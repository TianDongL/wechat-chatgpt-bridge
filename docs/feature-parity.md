# 现用能力对齐清单

核对日期：2026-11-23，发布候选 `0.1.0-alpha.6`。本表按实际启用的路由、收发逻辑、本机通知、预览和进程生命周期核对；不以命令名称相同代替行为验收。公开源码不含个人账号、会话、房间、凭据、隧道配置或运行数据库。

默认 `setup` 使用专用可见浏览器，仅需网页账号。可选 `setup:native` 使用 Windows 本机 Codex 已登录账号，提供与现用部署同类的 GPT 会话接口和个人 Dot 收发。两种模式复用同一微信渠道、持久化账本、HTML 预览和本机通知。**Dot 是可选能力，并非所有 ChatGPT 账号都具备；普通网页模式不会伪造一个 Dot 会话。**

## 不属于已用功能的项目

- `/new`、`/ack`：按产品决定继续移除。新建 GPT 会话在网页完成，再用 `/cd` 选中。
- 开机自启：参考部署的计划任务、启动目录和当前用户 Run 项均未发现桥自启配置。进程守护不代表开机启动；本版不添加系统服务或自启。
- 定时任务编排：桥负责转发 Dot/本机程序主动发出的提醒，不自行解释自然语言建立定时任务。
- 私人 MCP 应用注册、专用回调隧道及固定会话/身份绑定：属于原部署的接线配置，当前直接收发无需公开复刻。可选本机模式会发现并验证安装者自己的账号、个人房间和成员。
- 图片、语音、文件、群聊、其他收件人、任意后端：当前均不纳入本版。

## 验证边界

表中“行为已实现”与“真实微信往返已验收”是两件事。本机真实只读检查已确认默认 GPT 会话、最近 12 项以及个人 Dot 基线，未向 GPT 或微信发送测试消息。新增能力的发送、去重和故障行为使用合成服务验证。全新账号配对、连续两次真实微信问答、切换时真实手机接收提醒，仍应按[验收清单](acceptance.md)完成。

新版网页的 DOM 标记来自一次只读现场检查，Copy 捕获使用合成页面验证；实际网页的 Copy 行为仍可能随界面变化。无法导出源码的站内组件不能保证完整复现。维护此表时，应在增加或删除功能的同一提交里更新对应测试与帮助文本。
