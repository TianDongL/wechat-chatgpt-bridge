## 新增回归覆盖

- 默认 GPT 快捷入口、可选 Dot 输入、重复选择不重置、未配置 Dot 时拒绝。
- GPT 等待期间 Dot 提醒继续回传；本机 notify 不受当前输入路由影响。
- 忙碌 FIFO、10 分钟过期、限流 Retry-After、90 秒只读确认、回执丢失后不重复写入。
- 切换时丢弃旧会话异步结果；已排队消息不静默改投新会话；长轮询不阻塞其他通道。
- 接受后的重启恢复、迟到完成回复、出站重复页、微信发送不确定、存储失败、账本容量边界。
- 已完成回复位于游标之前、回复早于提交确认到达时，按原用户消息 ID 清除等待状态；不回退游标、不重复发送，不用其他轮次、隐藏内容或未完成节点解除切换保护。
- 个人 Dot 身份和成员验证、账号切换拒绝、隐藏内容/推理/工具目标/未完成生成过滤。
- 当前网页 DOM 适配、页面 Copy 源文本的 CRLF/空行/Markdown/HTML 精确保留及剪贴板 API 恢复。OS 剪贴板读写次数为零。
- 本机控制鉴权、跨站请求拒绝、消息长度限制、请求去重与固定收件人。
- 既有 HTML 识别、隔离、原文下载、容量、隧道失败回退及手机尺寸交互检查仍通过。

## 先前已有证据

alpha.3 在 Windows 使用固定版本官方 cloudflared 2026.11.1 完成了合成内容的真实临时公网检查：预览页、组件页 HTTP 200，下载原文逐字一致，停止后本机监听关闭。alpha.4 未改动预览识别器/服务器/隧道安装模块；本次重新运行其自动化回归，并扩展了通知和独立出站路径。

候选二维码曾被手机识别进入确认页，但不能记作完整配对成功。当前源码归档验证只覆盖依赖安装、启动宿主与无凭据退出，不包括登录及真实聊天。

## 仍需真实账号验收

**尚未完成：全新微信配对、干净电脑上的真实连续两条问答、真实切换与 Dot 主动提醒同时到达手机、真实微信打开 HTML 组件，以及故障网络下的完整手机往返。** 本机接口只读可用不代表写入及全部账号可用；网页 DOM 核对不代表真实 Copy/提交流程已验收。
